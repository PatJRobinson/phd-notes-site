# GitHub and Zenodo Practice Artefacts

## What this is

Bounded source class for issues, releases, discussions, archived research software, and deployment traces.

## Why it matters

The search appendix report recommends using GitHub and Zenodo only where practice-facing material leaves traces that formal literature does not capture: tool evolution, deployment caveats, release notes, software artefacts, and community discussions.

## Role in this PhD

Use as a search/source category, not as uncontrolled anecdotal evidence. Relevant to RQ1/RQ2/RQ3 when public practice artefacts illuminate assumptions, configuration, integration, or deployment.
