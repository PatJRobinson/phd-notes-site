# Compiled Notes

This directory is a compiled notes layer: a derived, current-facing view over the historical/source notes in the rest of the repository.

The source notes remain the archaeological record. They include dated framings, experiments, draft arguments, devlogs, working anxieties, and superseded language. This compiled layer does not replace them and should not be treated as the canonical history of the project.

Compiled notes are build output. They may be regenerated, revised, or recompiled around a different target. Their purpose is to reduce interpretation burden by extracting active concepts, candidate arguments, evidence clusters, tensions, and reading routes from the source archive.

Every substantive claim in this layer should point back to source notes using relative links where possible. Where a claim is inferred across several notes rather than directly stated in one note, it is marked as `Synthesised`.

Contradictions are preserved as research material. A disagreement between notes may appear here as an open tension, a historical precursor, a superseded framing, a recoverable fragment, or a candidate thesis move rather than being silently resolved.

Current target for this bootstrap compile: `rq3`.
