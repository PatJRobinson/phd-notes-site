# Interface

## What it is

An interface is a point of interaction between components, tools, frameworks, people, or organisational responsibilities.

## Why it matters

Interfaces are where meanings, assumptions, authority, data, timing, and responsibility are translated between layers.

## In this PhD

Interface is a cross-layer concept that includes APIs, system boundaries, tooling boundaries, responsibility boundaries, and deployment boundaries.

## In RQ3

It is the main analytical object: RQ3 asks how safety/security concerns emerge and are managed across interfaces.
