# Braun and Clarke — Reflexive Thematic Analysis

## What this is

Methodological anchor for reflexive thematic analysis. The theoretical foundation report stresses that thematic analysis is a method rather than a fully specified methodology, and that reflexive TA requires explicit conceptual and theoretical design work.

## Why it matters

The study can use prior theory as sensitising concepts without turning the extraction template into a fixed coding frame. The report recommends a theory-informed, abductive, reflexive TA, probably from a contextualist position.

## Role in this PhD

Use to justify a two-stage analytic architecture:

1. apply an assumption-elicitation protocol across artefacts and accounts;
2. analyse the resulting assumption records using reflexive, abductive, theory-informed TA.
