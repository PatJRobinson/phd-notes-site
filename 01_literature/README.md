# Literature Notes

## Current use

This folder is now organised around the progression-stage literature architecture described in the commissioned reports from July 2026.

The active literature position is:

- the thesis needs a structured integrative or systematized interpretive narrative review, not a full systematic literature review;
- the review should be strand-based because the project crosses software engineering, middleware, standards, assurance, safety/resilience theory, HCI, STS, and practice;
- anchor sources should be treated by what work they do in the thesis, not just by discipline.
