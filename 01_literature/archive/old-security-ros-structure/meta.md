# Literature organisation

## The three literature folders each serve a different analytical function

### A — Secure-by-Design and CPS security

**Purpose:**
Establish conceptual foundations for architectural security reasoning.

**Types of papers that belong here:**

- secure-by-design frameworks
- CPS security principles
- threat modelling theory
- architecture-level invariants
- information flow and integrity models
- systematic exploit papers if your purpose is “what architectural invariants did these violate?”

### B — ROS Architecture and Practice

**Purpose:**
Ground your understanding of how ROS systems are structured, built, deployed, and misconfigured.

**Types of papers that belong here:**

- ROS 2 design docs
- DDS architecture
- ROS deployment case studies
- vulnerabilities as they relate to ROS artefacts, communication patterns, or workflows
- “How X robot was built using ROS”
- any paper where your primary purpose is to understand ROS as actually used

### C — Developer Security & Tool Adoption

**Purpose:**
Understand why developers adopt/ignore security tooling and how workflow/cognitive factors shape decisions.

**Types of papers:**

- HCI-sec
- developer behaviour
- usability studies of security APIs
- organisational constraints
- human factors in robotics engineering
