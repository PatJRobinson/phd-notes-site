# SROS2

## What it is

SROS2 is ROS 2 security tooling and configuration around DDS Security concepts such as identity, permissions, governance, cryptography, and enclaves.

## What it anchors in the wiki

- [SROS2](../ros2/sros2.md)
- [Configuration](../concepts/configuration.md)
- [Safety/security relation](../assurance/safety-security-relation.md)
- [Assurance claim](../assurance/assurance-claim.md)

## What it contributes

SROS2 helps clarify how security mechanisms become concrete configuration and deployment work. It connects middleware security to integrator practice, policy management, and the maintenance of security-relevant assumptions.

## Limits / do not overuse for

Do not treat SROS2 documentation as proof that systems are secure when SROS2 is present. The wiki should distinguish mechanism availability from configuration correctness, deployment alignment, and assurance evidence.
