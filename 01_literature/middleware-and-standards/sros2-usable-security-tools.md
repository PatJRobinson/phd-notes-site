# SROS2 — Usable Cyber Security Tools for ROS 2

## What this is

ROS 2 security tooling anchor. The reports use SROS2 as a complement to the misconfiguration and security-documentation strands, showing that security depends on configuration, policy files, certificates, and middleware alignment.

## Why it matters

SROS2 is the official ROS 2 security tooling layer and a good example of how security becomes a usability, configuration, policy, and deployment problem.

## Role in this PhD

Use for RQ3 and for the safety/security strand. It should be important but not made into the whole thesis.
